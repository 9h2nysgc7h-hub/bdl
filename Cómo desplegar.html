Cómo desplegar la plataforma

Plataforma BDL · gratis de punta a punta

Mismo stack que ya usás en el CRM de Nave: Supabase (login + base de datos) + YouTube no listado (video) + Vercel (hosting). Los tres son gratis para este volumen de alumnos — no hay ningún paso pago acá.

1 · Crear el proyecto en Supabase

supabase.com → New project (plan gratis). Guardá la contraseña de la base que te pide, no hace falta para esto pero por las dudas.

2 · Cargar la base de datos

SQL Editor → New query → pegá todo el contenido de schema.sql → Run.
Después, otra query nueva → pegá todo el contenido de seed.sql → Run. Esto carga los 11 módulos y las 83 lecciones reales, sin video todavía.

3 · Activar logins sin confirmación por mail

Como los accesos los das vos a mano (no hay registro público), cuando crees cada usuario en el paso 5 tildá "Auto Confirm User" — así entra directo con la contraseña que le diste, sin tener que click-ear un mail de confirmación.

4 · Conectar el archivo con tu proyecto

Project Settings → API → copiá Project URL y anon public key. Abrí index.html, buscá las líneas SUPABASE_URL y SUPABASE_ANON_KEY cerca del principio del <script>, y pegalos ahí.

5 · Crear tu propio acceso como founder

Authentication → Users → Add user → tu email + una contraseña, con "Auto Confirm User" tildado.
Después, en SQL Editor, correr (reemplazando el email):
update profiles set rol='founder' where id = (select id from auth.users where email='tu-email@gmail.com');
Con eso ves el panel Admin al entrar.

6 · Subir a Vercel

Mismo flujo que ya conocés del CRM: creás el proyecto en Vercel y subís la carpeta Plataforma BDL (con el index.html ya configurado). Te da una URL tipo bdl-plataforma.vercel.app.

7 · Dar de alta a cada alumno

Authentication → Add user (con "Auto Confirm User" tildado) con el email y una contraseña provisoria que le pasás vos. El perfil se crea solo, arranca en Semana 0 (la única abierta por defecto).

8 · Cargar cada video a medida que lo grabás

Subís el video a YouTube como No listado (no público, no aparece en búsquedas — solo entra quien tiene el link). Copiás el ID de la URL: en youtube.com/watch?v=dQw4w9WgXcQ el ID es dQw4w9WgXcQ. Entrás a la plataforma logueado como founder → Admin → pegás el ID en la fila de esa lección → Guardar. Aparece al toque para todos los alumnos que ya tengan ese módulo desbloqueado.
El trade-off real de que sea gratis: "no listado" en YouTube no es lo mismo que privado — nadie lo encuentra buscando, pero si un alumno copia el link y se lo pasa a alguien de afuera, esa persona sí puede verlo. Para un programa de $2.000 con pocos alumnos por camada, es un riesgo bajo y es el mismo trade-off que acepta la enorme mayoría de cursos chicos. Si en algún momento esto crece y te preocupa de verdad, el salto siguiente es un hosting de video pago con protección real (Vimeo privado o Cloudflare Stream) — no hace falta ahora.

Desbloqueo semanal — es manual, lo hacés vos

Cada alumno arranca viendo solo la Semana 0. Cuando termina una semana y su entregable, toca "Avisar que terminé" dentro de la plataforma — vos ves ese pedido apenas entrás a Admin, en la sección "Pedidos de desbloqueo", con un botón para desbloquearle la semana siguiente. También podés adelantar o corregir la semana de cualquiera a mano, sin esperar su pedido, desde la tabla de Alumnos en el mismo panel.

Si ya tenías el proyecto armado antes de este cambio

Corré migracion-desbloqueo-manual.sql en el SQL Editor (una sola vez) — agrega las columnas nuevas sin tocar nada de lo que ya cargaste. No hace falta volver a correr seed.sql.
